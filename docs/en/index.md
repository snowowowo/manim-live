## Quick Start

```bash
pnpm add manim-live
```

After installing, pass in a container element and execute a piece of Python — that is the whole flow; the complete steps for installation, execution, and mounting in each framework are in [Quick Start](/en/guide/quick-start) and [Using in Frameworks](/en/guide/frameworks).
